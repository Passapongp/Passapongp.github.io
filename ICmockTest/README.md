# ซ้อมข้อสอบ IC Plain

เว็บหน้าเดียวสำหรับซ้อมข้อสอบหลักสูตรผู้แนะนำการลงทุนตราสารทั่วไป
เลือกคำตอบ เฉลยทันที แล้วขึ้นการ์ดหลักการของหัวข้อนั้นให้อ่านต่อ

ไม่มีขั้นตอนติดตั้ง ไม่มี build ไม่มี dependency
**ดับเบิลคลิก `index.html` ก็ใช้ได้เลย** และวางขึ้น GitHub Pages ได้ทันทีเช่นกัน

---

## สิ่งที่ทำได้

| โหมด | ใช้ตอนไหน |
|---|---|
| ซ้อมทั้งฉบับ | จับเวลาเสมือนจริง เรียงตามบลูพรินต์ |
| ซ้อมรายหัวข้อ | รู้ตัวว่าหัวข้อไหนยังไม่แม่น |
| สุ่ม 20 / 50 / 100 ข้อ | ซ้อมสั้น ๆ ระหว่างวัน |
| ทบทวนข้อที่เคยตอบผิด | รอบเก็บตก ก่อนสอบ |

ท้ายชุดจะสรุปคะแนนรวม แยกคะแนนรายหัวข้อ และเช็กเกณฑ์ผ่านให้ทั้งสองเกณฑ์
คือ **70% ของทั้งฉบับ** และ **70% ของหมวดที่ 2** ซึ่งตกหมวดเดียวก็ตกทั้งฉบับ

สถิติเก็บไว้ใน `localStorage` ของเบราว์เซอร์ตัวเอง ไม่ถูกส่งไปที่ไหน
เปลี่ยนเครื่องหรือเปลี่ยนเบราว์เซอร์แล้วเริ่มนับใหม่

บนคอมพิวเตอร์กด `1`–`4` เพื่อตอบ และ `Enter` เพื่อไปข้อถัดไปได้

---

## โครงไฟล์

```
index.html          หน้าเว็บ
style.css           สไตล์ทั้งหมด ใช้ชุดสีเดียวกับเล่ม PDF
app.js              ตรรกะทั้งหมด ไม่มีข้อสอบอยู่ในไฟล์นี้เลย
data/
  topics.js         การ์ดหลักการรายหัวข้อ         -> window.IC_DATA_TOPICS
  questions.js      ชุดข้อสอบที่เขียนเอง 200 ข้อ   -> window.IC_DATA_QUESTIONS
  questions-mock.js ชุดสำหรับอ่านเอง              -> window.IC_DATA_MOCK   (อยู่ใน .gitignore)
```

`questions.js` กระจายตามบลูพรินต์จริงของข้อสอบ คือสองเท่าของจำนวนข้อในแต่ละหมวด

| หัวข้อ | ข้อสอบจริง | ชุดนี้ | | หัวข้อ | ข้อสอบจริง | ชุดนี้ |
|---|---|---|---|---|---|---|
| ตลาดการเงิน | 6 | 12 | | การรู้จักลูกค้า | 5 | 10 |
| ผลตอบแทนและความเสี่ยง | 12 | 24 | | ตราสารทุน | 17 | 34 |
| เศรษฐกิจ อุตสาหกรรม บริษัท | 12 | 24 | | ตราสารหนี้ | 17 | 34 |
| จรรยาบรรณและกฎเกณฑ์ | 15 | 30 | | กองทุนรวม | 16 | 32 |

ตำแหน่งเฉลยกระจายเท่า ๆ กันทั้งสี่ตัวเลือก (50/49/51/50) โดยตั้งใจ
เพราะชุดที่เฉลยกระจุกอยู่ข้อเดียวจะฝึกให้เดาจากตำแหน่งแทนที่จะอ่านโจทย์
ข้อที่ตัวเลือกเรียงตามลำดับตัวเลขอยู่แล้วถูกยกเว้นไว้ ไม่สลับ

`app.js` ไม่รู้จักข้อสอบข้อไหนเลย ทุกอย่างอยู่ใน `data/`
เปลี่ยนไปใช้กับวิชาอื่น = เขียนไฟล์ใน `data/` ชุดใหม่ ไม่ต้องแตะโค้ด

ข้อมูลโหลดด้วย `<script>` ไม่ใช่ `fetch` โดยตั้งใจ เพราะ `fetch` จะถูกเบราว์เซอร์
บล็อกเมื่อเปิดไฟล์จากเครื่องตรง ๆ ทำให้ต้องมีเซิร์ฟเวอร์เสมอ วิธีนี้ไม่ต้อง

## รูปแบบข้อมูล

หนึ่งข้อสอบ

```js
{
  id: "own-q1",           // ไม่ซ้ำกันทั้งคลัง ใช้จำว่าเคยตอบผิดข้อไหน
  set: "own",             // รหัสชุด
  setName: "ชุดเขียนเอง",  // ชื่อชุดที่จะแสดง (ไม่ใส่ก็ได้ จะแสดงว่า "ชุดที่ <set>")
  no: 1,                  // เลขข้อในชุด
  q: "...",               // โจทย์
  choices: ["...", "...", "...", "..."],   // 4 ตัวเลือกเสมอ
  answer: 2,              // 1-4 ไม่ใช่ index
  topic: "market",        // ต้องตรงกับคีย์ใน topics.js
  topicName: "ตลาดการเงิน",
  part: "1"               // หมวดของข้อสอบ ใช้เช็กเกณฑ์ผ่านแยกของหมวด 2
}
```

หนึ่งหัวข้อใน `topics.js`

```js
"market": {
  name: "ตลาดการเงิน",
  part: "หมวดที่ 1",
  questions: "ข้อ 1–6",
  key: "ประโยคเดียวที่สรุปว่าหัวข้อนี้กำลังพูดเรื่องอะไร",
  points: ["หลักที่ใช้ตัดสินข้อสอบได้จริง ข้อละหนึ่งบรรทัด", "..."]
}
```

ข้อที่ `choices` ไม่ครบ 4 หรือ `answer` ไม่อยู่ในช่วง 1–4 จะถูกกันออกจากคลัง
โดยอัตโนมัติ และหน้าแรกจะบอกว่ามีกี่ข้อที่ถูกพักไว้ — เว็บจะไม่ถามข้อที่พัง

## การ์ดหลักการ คือส่วน "ให้ความรู้"

การ์ดไม่ได้อธิบายรายข้อ แต่ให้**หลักของหัวข้อ** เพราะข้อสอบวนอยู่บนหลักเดิม
เกณฑ์ที่ใช้เขียน `points` คือ **อ่านการ์ดจบแล้วต้องตอบข้ออื่นในหัวข้อเดียวกันได้เอง
โดยไม่ต้องจำคำตอบของข้อที่เพิ่งทำ** — ถ้าเขียนแล้วไม่ผ่านเกณฑ์นี้ แปลว่ายังเป็น
คำอธิบายแบบหนังสือเรียน ไม่ใช่แบบเล่มติว

## ขึ้น GitHub

1. สร้าง repo ใหม่ แล้วเอาไฟล์ในโฟลเดอร์นี้ขึ้นทั้งโฟลเดอร์
2. `.gitignore` กัน `data/questions-mock.js` และโฟลเดอร์ `Source/` ไว้แล้ว
   — **ก่อน push ให้เช็กด้วย `git status` ว่าสองอย่างนี้ไม่ติดขึ้นไป**
3. เปิด Settings → Pages → Deploy from a branch → `main` / `root`

`data/questions.js` เขียนขึ้นเองทั้งหมด จึงเผยแพร่ได้
ส่วน `questions-mock.js` แปลงมาจากชุดข้อสอบของผู้อื่น ใช้อ่านเองได้ แต่เผยแพร่ไม่ได้

หลัง push แล้วเปิดเว็บ จะเห็นชุดเขียนเอง 200 ข้อเท่านั้น ซึ่งเป็นพฤติกรรมที่ถูกต้อง
